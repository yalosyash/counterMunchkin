# Счётчик для «Манчкина» [![Тесты](https://github.com/yalosyash/counterMunchkin/actions/workflows/tests.yml/badge.svg?branch=main)](https://github.com/yalosyash/counterMunchkin/actions/workflows/tests.yml)

Сайт помогает следить за уровнем и боевой силой персонажа во время партии. При изменении уровня сила автоматически меняется на столько же. Бонусы и штрафы учитывайте вручную кнопками «+» и «−» в карточке «Сила». Оба значения сохраняются в браузере.

Чтобы сбросить уровень и силу до 1, нажмите «Новая игра» под счётчиками и выберите «Начать». «Отмена» сохраняет текущие значения.
